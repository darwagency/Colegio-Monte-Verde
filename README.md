# Colegio Monte Verde

Sitio web del Colegio Monte Verde, construido con Next.js, React y TypeScript.

## Desarrollo local

```bash
npm ci
npm run dev
```

Abre http://localhost:3000 para ver el sitio.

## Noticias

Las noticias se mantienen como datos tipados en `src/data/noticias.ts`. Para agregar una noticia, sus imágenes optimizadas se guardan en `public/noticias`. Consulta [NOTICIAS.md](NOTICIAS.md) para ver los campos y el formato de imágenes.
